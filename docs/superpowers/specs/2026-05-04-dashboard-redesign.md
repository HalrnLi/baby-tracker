# Dashboard 首页重新设计

## 概述

重新设计 Baby Tracker 首页（Dashboard），解决两个问题：
1. 最近记录按类型合并（母乳/奶粉→喂奶，小便/大便→尿布），避免重复展示同类记录
2. 突出显示"上次喂奶/尿布距离现在多久"这一核心信息
3. 体重改为首页直接记录，无需跳转

## 区块详情

### 1. 头部（不变）

标题"宝宝护理追踪" + 右上角设置齿轮图标。不做任何改动。

### 2. 上次状态卡片

两个并排卡片，各占 50% 宽度。

- **纯展示**：不可点击，无点击态样式（无 hover/active 效果）
- **喂奶卡片**：显示最近一条喂奶记录的详情（母乳 X ml / 亲喂 / 奶粉 X ml）+ 距离现在的时间
- **尿布卡片**：显示最近一条尿布记录的类型（小便/大便）+ 距离现在的时间
- 时间使用 `formatTimeAgo`（X小时前 / X分钟前 / 刚刚）

### 3. 今日摘要

三个紧凑卡片横排，从当前的大卡片样式改为小型。

- **喂奶**：显示今日喂奶总次数。点击 → 弹出今日喂奶明细 Sheet（现有功能，代码已存在）
- **尿布**：显示今日尿布总次数。点击 → 弹出今日尿布明细 Sheet（现有功能，代码已存在）
- **体重**：显示最近一次体重值。点击 → 弹出记录体重的 Sheet（**新功能**）
  - 体重记录 Sheet：底部弹出，包含体重数值输入（kg），确认后调 `recordsApi.create` 保存，关闭 Sheet 刷新页面

### 4. 最近记录

按**方案 A** 合并：feed/pump/diaper 各取最近一条，最多 3 条。

- 图标和标签跟随具体记录内容（母乳/奶粉/小便/大便各有对应图标和文字）
- 底部两个链接并排："查看全部"→ `/history`，"数据统计"→ `/stats`

### 5. 快速记录 FAB

完全不动。右下角橙色 + 按钮，点击弹出 QuickEntrySheet。

## 数据逻辑变化

### RecentRecords 构建

```ts
// 改后：按主类型去重
const recent = [
  sortedRecords.find(r => r.type === 'feed'),
  sortedRecords.find(r => r.type === 'pump'),
  sortedRecords.find(r => r.type === 'diaper'),
].filter(Boolean) as RecordType[];
```

### Stats 计算

`lastFeed` / `lastDiaper` 计算逻辑不变，仍然从今天 feed/diaper 记录中取最近一条。

### 体重记录 Sheet

新增一个轻量组件 `WeightSheet`（或内联在 DashboardPage），包含：
- 体重输入（数字键盘，kg，支持小数点后一位）
- 确认按钮 → 调 API 保存
- 取消/点击遮罩关闭
